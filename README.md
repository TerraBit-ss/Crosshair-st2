# Прицел — оверлей-прицел для Android

Рисует прицел точно по центру экрана поверх любой игры. Не перехватывает нажатия.

## Настройки
- стиль: крест, T-образный (без верхней линии), круг, круг + крест, только точка
- длина, толщина, зазор от центра, радиус круга, точка в центре (в пикселях)
- чёрная обводка 0–6 px, непрозрачность 10–100 %
- цвет: пресеты и любой HEX
- смещение по X и Y (если игра рисуется не по центру экрана)
- живой предпросмотр, кнопка сброса

## Как собрать APK

**Вариант 1. GitHub (без компьютера не получится быстро, но бесплатно).**
1. Создайте репозиторий на github.com и загрузите в него все файлы проекта
   вместе с папкой `.github`.
2. Вкладка Actions → Build APK → Run workflow.
3. Через пару минут скачайте артефакт `crosshair-apk` (внутри `app-debug.apk`).

**Вариант 2. Android Studio на компьютере.** Откройте папку проекта и нажмите
Build → Build APK(s).

**Вариант 3. Командная строка.** Нужны JDK 17, Android SDK 34 и Gradle 8.9+:
`gradle assembleDebug`. Результат: `app/build/outputs/apk/debug/app-debug.apk`.

## Установка и запуск
1. Установите APK (разрешите установку из неизвестных источников).
2. Откройте «Прицел» → «Включить прицел».
3. При первом запуске разрешите «Поверх других приложений» и вернитесь назад.
4. Настройте прицел, откройте игру. Выключить можно в приложении или кнопкой в уведомлении.

Требуется Android 8.0 и новее.
